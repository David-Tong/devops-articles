# DevOps 实战文章集

本系列文章来源于日常工作中的 DevOps 实践经验，涵盖软件交付全生命周期的核心主题。文章注重落地性，结合真实场景、踩坑记录与解决方案，帮助团队建立可持续的 DevOps 工程文化。

## 系列目录

| 编号 | 系列 | 简介 |
|------|------|------|
| 01 | [制品交付](./01-artifact-delivery/README.md) | 软件制品的构建、打包、版本管理与分发 |
| 02 | [基础设施交付](./02-infrastructure-delivery/README.md) | 以代码方式管理基础设施的工程实践 |
| 03 | [站点可靠性工程](./03-site-reliability-engineering/README.md) | 用软件工程方法保障系统的可靠性与可扩展性 |

## 写作原则

- **来自实践**：每篇文章均源于真实工程场景，避免纯理论堆砌
- **问题导向**：从实际遇到的问题出发，阐述解决思路与权衡取舍
- **可复用**：提供可直接参考的配置示例、命令和检查清单
- **持续更新**：随工程实践演进，定期修订已有内容
